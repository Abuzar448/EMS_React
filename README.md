# 🚀 Employee Management System (EMS)

A modern, responsive, and high-performance **Task Management Dashboard** built with **React.js** and **Tailwind CSS**. This application features a dual-interface system for Admins and Employees to manage daily tasks seamlessly.


## ✨ Features

### 👤 For Admins
*   **Comprehensive Dashboard:** Monitor all employees and their task statuses (New, Active, Completed, Failed) at a glance.
*   **Task Assignment:** Create and assign new tasks to specific employees with categories, dates, and detailed descriptions.
*   **Real-time Updates:** Status tracking table that updates instantly as employees interact with their tasks.
*   **Responsive UI:** Fully optimized for mobile, tablet, and desktop views.

### 👥 For Employees
*   **Personalized Task List:** View tasks assigned specifically to you in a swipe-able horizontal list.
*   **Task Life-cycle Management:** Accept new tasks and mark them as 'Completed' or 'Failed' directly from the dashboard.
*   **Dynamic Counters:** Interactive cards showing the count of current tasks in each category.
*   **Data Persistence:** Uses LocalStorage to ensure your progress isn't lost on page refresh.

---

## 🛠️ Tech Stack

*   **Frontend:** React.js (Hooks, Context API, Refs)
*   **Styling:** Tailwind CSS (Responsive Design, Glassmorphism)
*   **State Management:** React Context API (Single Source of Truth)
*   **Storage:** Browser LocalStorage
*   **Icons & Fonts:** Google Fonts & Emoji support
